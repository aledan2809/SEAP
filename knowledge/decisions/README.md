# Architecture Decision Records (ADRs)

This folder contains all architecture decision records for SEAP.

## How to use
1. Copy the template from `C:\Projects\Master\knowledge\templates\adr-template.md`
2. Name it `ADR-XXX-short-title.md` (e.g., `ADR-001-database-choice.md`)
3. Fill in all sections
4. Update this README with the new ADR
